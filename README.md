# AndrewTriesToCode's Homebrew tap

Homebrew requires trusting formulae from third-party taps first:

```sh
brew update
brew trust --formula andrewtriestocode/brews/<formula>
brew install andrewtriestocode/brews/<formula>
```

| Formula | Description |
| --- | --- |
| [bg3mfx](https://github.com/AndrewTriesToCode/bg3mfx) | MetalFX upscaling and frame generation for Baldur's Gate 3 on Mac |
